Project Highlights

Programming Fundamentals

The Python and C++ projects demonstrate functions, loops, conditions, input validation, random-number generation, menu-driven applications, and basic transaction handling.

Machine Learning and Data Science

The projects cover data preprocessing, exploratory analysis, regression, classification, clustering, model evaluation, and result visualization. The Iris classifier achieved 90% test accuracy, while the customer-segmentation project produced five clusters with a 0.5547 silhouette score.

Computer Vision and Deep Learning

The computer-vision projects implement text extraction with OCR, facial-emotion recognition with convolutional neural networks, and real-time object detection using YOLO.

Generative AI

The Generative AI notebooks use Google Colab and a Tesla T4 GPU. Task 3 implements retrieval-augmented generation with an Unsloth Dynamic 4-bit Llama model. Task 4 combines Whisper speech recognition with a quantized instruction model for transcript processing and reasoning.

How to Run a Python Project

Open the required project folder in VS Code and run:

python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python <script_name>.py

Replace <script_name>.py with the Python filename present in that project folder.

Running the C++ Notebooks

The C++ tasks are provided as Google Colab notebooks because of local compiler configuration issues. Upload the required .ipynb file to Google Colab and run its cells sequentially.

Running the Generative AI Notebooks

Upload the required notebook to Google Colab.

Select Runtime > Change runtime type > T4 GPU.

Run the cells sequentially.

Upload the requested knowledge-base or audio file when prompted.
