# ATM Simulation

Arch Technologies Internship — Python Development, Month 2, Task 4.

## Project objective

This command-line application simulates basic ATM operations. A user can check the account balance, deposit money, withdraw available funds, and exit safely.

## Features

- Object-Oriented Programming using `ATM` and `ATMController` classes
- Balance inquiry
- Deposits with amount validation
- Withdrawals with insufficient-balance protection
- Invalid menu and non-numeric input handling
- Currency display in Pakistani rupees

## Requirements

- Python 3.10 or newer
- No external packages

## Run in CMD

Open CMD in this folder and execute:

```cmd
python atm_simulation.py
```

If required, use:

```cmd
py atm_simulation.py
```

## Save terminal output in CMD

After running the program, select and copy the terminal text into Notepad, then save it as `output.txt`. Also capture a screenshot using `Windows + Shift + S`.
