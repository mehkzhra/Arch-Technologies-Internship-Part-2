# Number Guessing Game

Arch Technologies Internship — Python Development, Month 2, Task 3.

## Project objective

The computer randomly selects a number between 1 and 100. The player enters guesses, and the program reports whether each guess is too high or too low until the correct number is found.

## Features

- Random number generation from 1 to 100
- Too-high and too-low hints
- Input validation for non-numeric and out-of-range values
- Attempt counter
- Option to play multiple rounds

## Requirements

- Python 3.10 or newer
- No external packages

## Run the program

Open PowerShell or the VS Code terminal in this folder and run:

```powershell
python number_guessing_game.py
```

If `python` is not recognized, try:

```powershell
py number_guessing_game.py
```
